# Source Repositories

This project references the following external repositories which should be cloned separately:

## Required Repositories

| Repository | Clone Command |
|-----------|--------------|
| hz12opensource/libresdr | `git clone --depth 1 https://github.com/hz12opensource/libresdr.git` |
| lucasmellon-ops/LibreSDR | `git clone --depth 1 https://github.com/lucasmellon-ops/LibreSDR.git` |
| F5OEO/tezuka_fw | `git clone --depth 1 https://github.com/F5OEO/tezuka_fw.git` |

## Cloning All Sources

```bash
# Clone main repo
git clone https://github.com/ta1rjv/libre-kb.git
cd libre-kb

# Clone source repos
git clone --depth 1 https://github.com/hz12opensource/libresdr.git
git clone --depth 1 https://github.com/lucasmellon-ops/LibreSDR.git
git clone --depth 1 https://github.com/F5OEO/tezuka_fw.git
```
